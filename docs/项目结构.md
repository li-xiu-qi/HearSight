# 项目结构

HearSight 为本地优先的单体全栈架构：一个 Next.js 应用承载前端与后端（API 路由即后端），数据落 SQLite 单文件，任务进度走进程内事件推送；语音识别、向量、大模型三个 AI 能力是独立的本地服务，通过 HTTP 与 Web 层连接，可分别替换或指向外部 API。

## 数据流

上传或链接下载的媒体先由 Web 层落盘，抽音轨后调用 ASR 服务拿句级时间戳与说话人分离结果，写入 SQLite；摘要、翻译、问答由 Web 层直接调用 LLM 服务完成，问答额外经 embedding 服务做向量检索，检索不到时降级为关键词匹配。任务全程在 Web 层进程内执行，进度通过服务端事件推给前端。
