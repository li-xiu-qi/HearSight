# 🚀 快速开始（本地模式）

HearSight 现为本地优先的单体全栈架构：一个 Next.js 应用（前后端同仓）+ 三个可替换的本地 AI 服务，数据落在 SQLite 单文件，不需要数据库服务器、消息队列或容器。

### 🔥 获取源代码

```bash
git clone https://github.com/li-xiu-qi/HearSight
cd HearSight
```

### ⚙️ 环境要求

| 组件 | 要求 |
|------|------|
| Node.js | 20+ |
| Python | 3.10+（三个 AI 服务各自一个虚拟环境） |
| ffmpeg / yt-dlp | 用户态安装即可，路径可用环境变量覆盖 |
| GPU | NVIDIA（语音识别、向量、推理三个本地服务） |

不强制要求 GPU 也能跑：把 AI 服务指向别处（见下方「切换外部服务」），只起 Web 层即可。

### 📦 安装与构建

```bash
cd next-app
npm install --include=dev   # --include=dev 不能省，否则跳过类型检查
npm run build
cd ..
```

### ⚙️ 环境配置（可选）

缺省全部指向本机回环，零配置可跑。只在偏离默认布局时创建 `next-app/.env.production`：

```bash
cp next-app/.env.production.example next-app/.env.production
```

逐项说明见该文件，常用覆盖项：数据目录 `HEARSIGHT_DATA_DIR`、三个 AI 服务地址、LLM 的 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`、外部工具路径。

### 🤖 启动 AI 服务

Web 层之外有三个独立进程，按需启动（只影响对应能力，未启动时相关功能降级或报错）：

1. **语音识别**（`ASRBackend/`）：本地 FunASR 模式

   ```bash
   cd ASRBackend
   ~/hearsight-env/bin/uvicorn main:app --host 0.0.0.0 --port 8003
   ```

   依赖见 `ASRBackend/requirements-local.txt`。注意 torchaudio 需按 PyTorch 官方 cu130 源单独安装，版本须与 torch 同源，否则首个转写请求会报 fbank 后端缺失。模型首次运行从 modelscope 自动拉取（约 1.3GB）。

   云端路线保留：设 `ASR_MODE=cloud` 并配 `DASHSCOPE_API_KEY` 即走阿里云百炼的识别接口（有免费额度），代码未改动。

2. **向量检索**（`ai-services/embedding/main.py`）：本地 bge-m3

   ```bash
   HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 ~/xinfer-env/bin/python ai-services/embedding/main.py --port 8004
   ```

   离线标志不能省，否则加载模型时会因连不上 huggingface.co 而卡住重试。

3. **大语言模型**：任何 OpenAI 兼容服务。本机示例为 llama-server：

   ```bash
   llama-server -m <gguf 模型路径> --host 0.0.0.0 --port 8080 -ngl 99 -c 8192
   ```

### 🖥️ 启动 Web 层

```bash
bash scripts/start-local.sh          # 默认端口 9187
bash scripts/start-local.sh 3000     # 指定端口
```

启动后访问 <http://localhost:9187>。

### 🔀 切换外部服务

LLM 层走 OpenAI 兼容协议，改三个环境变量即可切到外部 API（硅基流动、百度 AI Studio 等），无需改代码：

```bash
LLM_BASE_URL=https://api.siliconflow.cn/v1
LLM_API_KEY=sk-xxx
LLM_MODEL=deepseek-ai/DeepSeek-V3.2-Exp
```

Embedding 同理（`EMBEDDING_BASE_URL` / `EMBEDDING_API_KEY` / `EMBEDDING_MODEL`）。

### 💾 数据与备份

所有数据在 `HEARSIGHT_DATA_DIR`（缺省 `<仓库>/app_datas`）：

- `hearsight.db`（SQLite，WAL 模式）：转写稿、摘要、翻译、任务记录
- `download_videos/`：上传与下载的媒体文件
- `tmp/`：处理中间产物

个人使用场景下备份 = 拷贝这一个目录。注意 WAL 模式下需连同 `-wal` / `-shm` 两个附属文件一起拷，或在无写入时用 `sqlite3 hearsight.db ".backup"` 做一致性快照。
